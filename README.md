# 르모아 · Le Moa

가게에서 멤버십 혜택을 먼저 확인하고, 사용할 결제카드 앱으로 연결하는 Android 우선 앱입니다. Expo / React Native / TypeScript로 개발하며 PC 브라우저에서도 화면 흐름을 테스트할 수 있습니다.

## 첫 버전 이용 흐름

1. 가게를 검색하거나 선택합니다.
2. 보유한 멤버십·브랜드 쿠폰 안내를 확인하고 해당 앱을 엽니다.
3. 외부 앱에서 바코드·쿠폰을 제시하고 직원에게 혜택을 적용받습니다.
4. 르모아로 돌아와 결제카드 앱을 엽니다. **할인 후 금액 입력은 필요하지 않습니다.**
5. 열린 카드사 앱에서 카드와 결제 메뉴를 선택합니다.

외부 앱 실행은 할인 적용이나 결제 완료를 의미하지 않습니다. 멤버십 앱에서 이미 결제한 경우 추가 결제하지 않습니다.

## 지원 범위

- 통신사: SKT T 멤버십, KT 멤버십, LG U+ 멤버십(U+one)
- 브랜드: 파리바게뜨, 스타벅스, 맥도날드, 파파존스, 아웃백, 버거킹, KFC, CU, 올리브영
- 카드: 하나 SK패밀리카드(마트형), 롯데 힐튼 아너스 아멕스 프리미엄, 현대 the Pink Edition3, 현대 ZERO Edition3(포인트형)
- 결제 앱 연결: 하나Pay, 디지로카, 현대카드, 삼성 월렛
- 공식 가게 로고 9종·실물 대표 카드 디자인 4종, 카드 상세 혜택, 가게별 조건부 할인/적립률
- 보유 멤버십·카드 저장, 주카드 지정, 큰 글씨 모드
- 통신사·아웃백 등급 선택, T 할인형/적립형 선택, 기타 브랜드 등급 메모 (기기 내 저장)

브랜드별 혜택 안내와 공식 앱 경로를 제공합니다. 9개 브랜드 모두의 상시 SKT 할인을 의미하지 않습니다. 실제 할인·적립 조건은 지점, 상품, 등급, 주문 방식과 쿠폰에 따라 확인해야 합니다.

## PC에서 실행

Node.js 24 LTS와 npm을 준비한 뒤 실행합니다.

```sh
cd mobile
npm ci
npm run export:web
npm run preview
```

브라우저에서 <http://127.0.0.1:4173/>에 접속합니다. 실행 중인 서버가 있어야 연결됩니다. 서버는 로컬 컴퓨터에만 바인딩합니다.

개발 중 변경을 바로 확인하려면 다음 명령을 사용합니다.

```sh
cd mobile
npm run web
```

PC에서는 멤버십·결제 앱 실행 대신 **앱 연결 미리보기**를 표시합니다. 실제 바코드 제시와 결제 기능을 에뮬레이션하지 않습니다.

## Android

공식 Google Play에서 확인한 패키지 ID로 앱을 실행하고, 실행 실패 시 해당 스토어 페이지로 안내합니다. 바코드 화면 직행 경로는 확인되지 않아 앱 첫 화면을 엽니다. 패키지 조회 범위는 `mobile/plugins/withAppQueries.js`에서 제한적으로 선언합니다.

- Android 코드 번들 생성은 확인했습니다. 서명된 APK/AAB는 아직 제공하지 않습니다.
- 실제 기기에서 외부 앱 실행·미설치 처리·복귀 흐름을 추가 검증해야 합니다.
- QR 자동 생성, 카드 자동 선택, 삼성페이 결제 SDK 연동, 결제 승인 확인은 구현하지 않았습니다.
- iOS 외부 앱 연결과 GPS 기반 가게 인식은 후속 범위입니다.

## 검증

```sh
cd mobile
npm run lint
npm run typecheck
npm test
npm run export:web
npx expo export --platform android --output-dir dist-android
```

테스트 17개는 검색·연결 데이터·등급별 혜택·카드별 단위와 조건·설정 복구를 검증합니다. Expo 린트와 TypeScript 검사를 제공합니다.

## 구조

- `mobile/App.tsx`: 화면과 사용자 흐름
- `mobile/src/catalog.json`: 브랜드·멤버십 앱·카드·공식 안내 데이터
- `mobile/src/domain.ts`: 검색, 보유 설정, 카드 정렬, 화면 상태 전환
- `mobile/src/launch.ts`: 플랫폼별 외부 앱 연결
- `mobile/scripts/preview.mjs`: PC 미리보기 서버
- `mobile/tests/`: 도메인 테스트
- `docs/`: 의존성 라이선스 목록과 제3자 고지

## 데이터·상업화 관련 현재 상태

보유 설정은 기기·브라우저에만 저장합니다. 카드번호, 로그인 정보, 위치는 수집하지 않습니다. 외부 AI 모델·유료 API는 사용하지 않습니다. 카드별 조건부 할인/적립률을 표시하며, 지정한 주카드를 우선 표시합니다. 개인 실적·잔여 한도·등급 자동 조회와 최적 카드 순위/현금 환산은 제공하지 않습니다.

공식 이미지 출처와 혜택 검증 근거는 [출처 문서](docs/ASSET_AND_BENEFIT_SOURCES.md)에 있습니다. 브랜드 이미지의 상업적 재배포 허가는 별도 확인 대상입니다.

`mobile/LICENSE`는 Expo 템플릿의 원 저작권 고지입니다. 앱 전체에 대한 별도 배포 라이선스 선언은 아닙니다. 의존성 고지는 `docs/THIRD_PARTY_NOTICES.txt`, 목록은 `docs/dependency-licenses.json`에 있습니다. 실제 배포 시 포함 의존성의 라이선스 의무와 각 서비스의 브랜드·연동 조건을 확인해야 합니다.

```sh
cd mobile
npm run licenses
```
